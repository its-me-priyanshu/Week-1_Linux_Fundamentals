# Systemd Service Management
**Objective**

Learn how to create and manage a custom systemd service in Linux. You will create a shell script that logs the current date and time, configure it as a systemd service, enable automatic restart on failure, and ensure it starts automatically after every system reboot.

## 1. Create a Shell Script.
- Create a script that continuously write the current date and time into a log file .

```bash
sudo vi /usr/local/bin/date_logger.sh
```

- /usr/local/bin/ = Its a standard directory for custom executable scripts.
---
```bash
#!/bin/bash
 while true
 do 
    echo "$(date)" >> /var/log/date_logger.log
    sleep 10 
done
```
**Breakdown :**

- **#!/bin/bash** = called the Shebang, it tell linux to execute this script using the Bash shell.

- **While true** = Create  an infinite loop, so the script keeps running untill it is manually stopped.
- **echo "$(date)"** = **date** is print the current date and time,  **doller( )** execute the cmd inside it.
- **echo** = it print the result.

**Output :**
> Tue Aug 4 12:30 IST 2026

**>>** **Append Operator** = Instead of overwriting the file, it adds new data at the end .

- **/var/log/date_logger.log** = log file where timestamps are stored.
- **sleep 10** = Wait for the 10 sec before writing the next timestamp.
---
## Make the Script Executable.
```bash
sudo chmod +x /usr/local/bin/date_logger.sh
```
**Verify :**
> ls -l /usr/local/bin/date_logger.sh

**Output :**

## 2. Create a Systemd Service File.
```bash
sudo vi /etc/systemd/system/date_logger.service
```
- **/etc/systemd/system/** = Directory for custom system services.
- **date_logger.service** = Service configuration file.

**Service file :**
```test
[Unit]
Description=Date Logger Service
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/date_logger.sh
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
---
**Breakdown :**

**[Unit]**

- Contains general information about the service.

**Description=Date Logger Service**

- Provides a human-readable description.

> Example:
```
Description=Backup Service
Description=Web Server
```

**After=network.target**

- Starts this service only after the networking system is available.

- Although this script doesn't require networking, it demonstrates dependency ordering.

**[Service]**

- Defines how the service should run.

**Type=simple**

- Indicates the service starts immediately and continues running in the foreground.

- Suitable for scripts that don't fork into the background.

**ExecStart=/usr/local/bin/date_logger.sh**

- Specifies the exact command systemd executes when starting the service.

**Restart=always**

- Automatically restarts the service whenever it stops.

- Whether it exits normally or crashes, systemd starts it again.

**RestartSec=5**

- Waits 5 seconds before restarting the service.

- This prevents rapid restart loops.

**[Install]**

- Defines when the service should start.

**WantedBy=multi-user.target**

- Starts the service automatically when Linux reaches multi-user mode (normal operating mode).

- Equivalent to the normal command-line boot level.

---
## Reload Systemd.
- Whenever a new service is created, systemd must reload its configuration.

```bash
sudo systemctl daemon-reload
```
- **systemctl** = Controls systemd services.
- **demon-reload** = Reloads all service configuration files.

---
## 3. Start the Service.
```bash
sudo systemctl start date_logger.service
```
## 4. Enable Service at Boot.

```bash
sudo systemctl emable date_logger.service
```
- **enable** = It makes service start automatically after every reboot.

**Output**
> Created symlink ...

## Configure automatic Restart.
```
Restart=always
RestartSec=5
```
- Whenever the service stop, systemd waits for 5 sec and start it again.

## Useful Commands and Their Breakdown.

- **systemctl demon-reload** = Reloads systemd configuration after creating or modifying service files.
- **systemctl enable service** =	Enables automatic startup after boot.

- **systemctl disable service** = Disable automatic startup.

- **journalctl -u service** = Shows logs generated by the specified service

- **pkill -f process_name** =	Terminates a process by matching its command line.
